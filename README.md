# Projeto Petly Pet Shop Fictício — Fase 1

Petly é um site acadêmico de um pet shop fictício, desenvolvido em HTML para a disciplina de Fundamentos de Sistemas Web da PUCRS. O site apresenta um catálogo de produtos com fotos, descrições e preços, além de serviços de banho e tosa com a opção de tele-busca.

## Como abrir o site

1. Baixe ou clone o repositório. Se baixou o arquivo ZIP, extraia a pasta.
2. Mantenha os arquivos HTML e a pasta `_imagens` na mesma pasta.
3. Abra [index.html](index.html) no navegador. Use o menu para acessar as demais páginas.

## Páginas e funcionalidades

| Página | O que você encontra |
| --- | --- |
| [Início](index.html) | Destaques da Petly, produtos com links para o catálogo e serviços com links para os detalhes. |
| [Sobre nós](sobre.html) | Apresentação, valores e proposta de atendimento da Petly. |
| [Produtos](produtos.html) | Catálogo de acessórios, rações não perecíveis e produtos de higiene e limpeza, além de sachês e petiscos. Cada item tem foto, descrição e preço. |
| [Serviços](servicos.html) | Descrições e valores de banho, tosa, cuidados complementares e pacotes. |
| [Agendamento](agendamento.html) | Orientações de atendimento, WhatsApp demonstrativo e condições da tele-busca. |
| [Comunidade](comunidade.html) | Galeria de pets e dicas sobre brincadeiras, comportamento e rotina. |
| [Petly Recomeço](recomeco.html) | Campanha fictícia de adoção responsável, com perfis de cães e gatos. |
| [Contato](contato.html) | Canais demonstrativos, localização fictícia e perguntas frequentes. |


## Navegação por teclado

Pressione Tab ao abrir qualquer página para alcançar o link **Pular para o conteúdo** e Enter para ativá-lo. Na página inicial, o nome e a foto de cada produto em destaque compartilham um link que leva ao item correspondente no catálogo.
